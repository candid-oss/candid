# 决定索引

**状态**：已生效（2026-11-26 起）。

本目录记录「为什么这么定」。它只追加，不改写：新决定写新的一条，旧的标「被 NNN 取代」。现行规则不在这里，在[规格](../specs/README.md)里；本目录只回答规则当初为什么是这样、还考虑过什么。

## 两种记录的分工

| 种类 | 位置 | 什么时候用 | 格式 |
|---|---|---|---|
| 决定流水 | [log.md](log.md) | 每一条设计决定，一行：日期、决定、一两句理由、落在哪份规格。被推翻的决定不删，在新的一行写「取代」 | 表格，最新在上 |
| 决策记录（ADR） | `NNN-<标题>.md` | 影响结构、难以反悔的决定；理由写不进一两句话。需要写背景、考虑过的选项、决定、代价、影响到的文档 | 见[文档规范](../standard.md#templates) |

流水里的某一行理由写不下时，升格为决策记录，流水里留链接。

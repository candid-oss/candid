# 决定流水

**状态**：已生效（2026-11-26 起）。只追加，不改写。

本文按时间倒序记录每一条设计决定：一行一条，写明日期、决定、一两句理由，以及它现在体现在哪份规格。影响结构、难以反悔的决定写成[决策记录](README.md)，这里只留一行链接。格式见[文档规范](../standard.md#history)。

约定：

- 日期写「≤日期」表示原文没有注明日期，该日期是原文件首次进入仓库的日期（决定不会晚于它）；本文没有无法判断的条目。
- 决定末尾的方括号标出来源：T 是 `timeline-v1`，A 是 `agent-platform-v1`，D 是 `data-model-v1`，U 是 `design-system-v1`，P1 是 `ai-v1-plan`，P2 是 `data-layer-v1`，N 是本次工程整理。后面的数字是旧文档章节号。
- 「落在」列写这条决定现在体现在哪份文档；旧章节号去了哪里见[搬迁对照页](../specs/README.md#legacy)。被推翻或取代的决定不删，在取代它的那一行写明「取代」。
- 排序：大体按日期倒序；带「≤」的条目按来源文件成组，放在其上限日期附近（它们实际发生的时间可能更早，且彼此之间的先后不详）。

# 版本记录

**状态**：维护中。最新的在最上面；合并进主分支的改动先记在「未发布」，发布时改成版本号和日期。

这份记录回答「每个版本做成了什么」，只写用户或后续开发者能感知的结果。版本号规则、条目格式见 [文档规范 §9](standard.md#versions)。表结构版本（`SCHEMA_VERSION`）是另一个数，记在各版本的「内部」里，不与产品版本号混用。待办和排期在路线图，不在这里。

## 未发布

**主题**：把采集到的原始记录整理成 AI 能直接读的对话、摘录、活动块、人物和条目，并把存储、功耗、迁移和首次使用补到能日常用的程度。

### 新增
- AI 默认读「整理层」：邮件、录音转写、AI 会话和截图里的聊天都变成统一的对话与消息，浏览器和文档的正文变成摘录；新增 `find`、`conversations`、`conversation`、`evidence` 工具，原始记录只作为证据按需下钻。（[整理层](specs/curation.md)）
- 聊天截图会变成真实的消息：OCR 坐标判断左右和顺序，视觉模型只负责结构，与对话末尾对齐并去重；需在设置里开启「屏幕对话与摘录」。（[整理层](specs/curation.md)）
- 「帮我写」面板（默认 ⇧⌘J）：根据当前对话和你的历史发言起草回复，插入原输入框，不代发。（[工作流](specs/workflows.md)）
- 活动块：把一段屏幕活动概括成「14:00–15:30 在做什么」的一句话，只读整理层生成，随整理层的更正自动跟进；新增 `day` 工具。（[整理层](specs/curation.md)）
- 人物归一：按邮箱、声纹、同应用同名等规则自动合并；你的合并、拆分、改名、「不是同一人」挂在别名上，重算不丢；模型只判断剩下的候选对，结果有佐证才自动生效，否则出现在「可能是同一人」卡片里，可撤销；新增 `person` 工具。（[人物与条目](specs/people-items.md)）
- 条目抽取：从对话里抽出日程、提醒、备忘和承诺，提案经确认后才写入日历和提醒；AI 页按条目分组；新增 `items` 工具。（[人物与条目](specs/people-items.md)）
- 屏幕截图存储预算：超出目标容量时按规则淘汰旧截图，到目标即停。（[存储](specs/storage.md)）
- 首次使用引导（欢迎、采集等级、权限、AI、完成）和常驻的健康检查：权限丢失、核心连接、截图存储、三个模型角色不可达时，菜单栏圆点变色并给出修复按钮。
- 悬浮球成为 Candid 的主入口，支持按住说话的语音输入。
- 与 macOS 打通：快捷指令、专注模式过滤、`candid://` 链接、登录时启动。（未验证）
- `candid backup`、`restore`、`move-root`：整体备份、恢复和搬移资料库，App 运行中也能做一致性快照。（[数据位置与迁移](data-migration.md)）
- `candid-lab` 实验工具：在真实数据的副本上复跑后台流程、缓存模型回复、对比不同读法与模型。（[数据层实验](plans/data-layer-lab.md)）

### 改变
- 新增「后台处理」开关（AI 设置顶部）：随时 / 省电（默认）/ 手动。省电档用电池时不跑本机模型，接电源后自动继续；等待中的条目可点「现在处理」。截图识别原有的电量、插电时长、批次等电源选项全部并入这一个开关。（[模型](specs/models.md#power)）
- 一条录音只转写一遍：录音结束后一个作业同时得到文字、说话人和声纹，录音进行中不跑模型；语音服务常驻、空闲 10 分钟卸载模型，不再每段重新加载。（[工作流](specs/workflows.md)）
- 空闲时不再定时醒来：核心后台线程、App 各页面刷新、agent 目录同步都改为有事件才动。
- 设置页显示一行能耗账「今天后台计算 X 分钟，等待 N 项」；新增 `energy_summary` 工具。（[查询](specs/query.md)）
- 新截图存成 WebP，处理后的录音存成 AAC；已有的 JPEG 截图和旧 WAV 录音由后台转换。（[存储](specs/storage.md)）
- 录音直接写成分段 AAC，每段十分钟，崩溃后保留到最后一秒；录音菜单里的「每 30/60 秒保存」取消。
- 说话人分离改为对整段录音按重叠窗口处理，可中断续跑，一次得到一套统一的说话人；声纹只算一次并按语音时长确认姓名。（[模型](specs/models.md)）
- 模型调用分为交互和后台两条通道：对话与「帮我写」不再被后台任务挡住；后台作业有优先级、统一的限额与重试。（[模型](specs/models.md)）
- AI 设置合并到一处：模型来源、角色编辑、工作流与数据权限新视图，旧的模型设置和 AI 控制面板移除。
- 派生的 JSON 原件压缩存放，WAL 设上限，库更小。（[存储](specs/storage.md)）
- 语音转写遇到模型长度上限时拆成两半重试，不再保留被截断的结果。
- 需要 Xcode 26 构建。

### 修复
- 本地模型不再因收到 WebP 而拒收截图（本地给 PNG，云端仍给 WebP）；输出上限遵守角色设置；截图积压按采集顺序处理。（[整理层](specs/curation.md)）
- 聊天对话身份以 OCR 头部规范化为准，不再产生以应用命名的空对话；减少幻觉消息、AX 噪声、拆碎的会话和人物误合并。
- 人物判断的回复会对照候选批次校验，不接受批次之外的结果。
- 备份跳过被锁的数据库；若干在 macOS CI 上偶发失败的测试已稳定。

### 内部
- 表结构版本 8 → 13（v13 作业能耗账）：v9 屏幕片段输入只存一份；v10 屏幕输入与证据选择器压缩；v11 整理层派生表（对话、消息、摘录及全文索引）；v12 条目表、AI 会话类对话、说话人标签、AX 摘录。升级均带测试。（[数据模型](specs/data-model.md)）
- MCP 契约变化：新增 `find`、`conversations`、`conversation`、`evidence`、`day`、`person`、`items`，默认暴露整理层，旧工具保留；契约快照（`core/fixtures/contract/`）与全流程测试（`lifecycle`）在 2026-11-25 建立，之后工具清单或提示词变化必须重新生成快照。（[契约清单](contracts/README.md)）
- 新增全流程测试：固定三天假数据加回环模型桩，覆盖入库、整理、摘录、活动块、人物、条目到 MCP 查询。
- 新增仓库规则 `AGENTS.md`；CI 只跑基础检查，完整的 macOS App 测试按需运行。
- 本次文档体系重构：新增[文档规范](standard.md)、[产品定位](product.md)、[架构总图](architecture.md)、[工程规范](engineering.md)、[契约清单](contracts/README.md)；规格按主题拆分为 storage、data-model、curation、people-items、models、query、connectors、workflows、design-system；新增 `scripts/check.sh` 与 `scripts/check_docs.py`，一条命令检查文档与代码。
- 核心版本号仍为 0.1.0（`core/Cargo.toml`），下次发布时再升。

## 0.1.0 · 2026-11-18

**主题**：首个公开版本：本地采集、统一时间线库、给 AI 的查询入口。提交 `4650ac2`，标签 `v0.1.0`；表结构版本 8。

### 新增
- 电脑活动采集：应用、窗口、焦点与选中文字、可读的页面文字，可按应用开关和排除。（[桌面采集](specs/connectors.md)）
- 截图：只在开启并选择应用后记录，文字识别在本机完成。
- 录音：麦克风与系统声音（例如通话），分段保存，崩溃也不丢。
- 本地语音转写与说话人分离（Apple Silicon，可选的外部语音服务）。（[模型](specs/models.md)）
- 邮件与日程：本机「邮件」数据或 IMAP，可设筛选规则；日历与提醒显示在 AI 页；浏览器历史连接器已有但默认不导入。（[连接器](specs/connectors.md)）
- AI 会话：读取 Claude Code、Codex 里的指令并关联到当时的活动。（[连接器](specs/connectors.md)）
- 统一时间线库：SQLite 加原件，入库幂等、可恢复，原桌面账本迁入后只读保留。（[存储](specs/storage.md)）
- 查询与权限：HTTP、MCP 和 `candid` 命令行三种访问方式，按范围的令牌，所有访问记入审计。（未验证）（[查询](specs/query.md)）
- 模型来源与用量：本地与云端模型可配置，每次调用有记录。（[模型](specs/models.md)）
- AI 页挂接 Pi 对话与技能；外部 agent 走 MCP。（[工作流](specs/workflows.md)）
- Mac App：菜单栏状态、时间线界面，中文与英文界面；发布包使用临时签名。（未验证）（[设计系统](specs/design-system.md)）

### 内部
- Rust 核心作为 App 包内辅助进程运行，Swift 只经本地通道调用。
- 表结构版本 8。

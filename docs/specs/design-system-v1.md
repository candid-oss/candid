# 界面设计规范 v1（Mac）

**中文** · [English](design-system-v1.en.md)

本页维护 Candid Mac 客户端的设计逻辑和使用规则：遇到一类界面问题时怎么选、用哪个组件、哪些做法不允许。

- **数值**：字号、间距、圆角、底色深浅、颜色、动效参数只在代码 [`DesignSystem/`](../../apps/macos/Sources/Candid/DesignSystem/) 中定义，本页只写名字和用途，不抄数值。
- **样张**：启动时加 `--design-specimen`，顶栏多出调色板按钮，打开由真实组件渲染的样张页；右上角可切换三种风格。

> 决定：新功能视觉效果照原来做，沿用现有组件、样式与风格，不另做一套视觉设计。双排时间线、连接页及常用操作继续按接口实现。
>
> 决定：主页时间线按确认的多轨样张 v2 改为一根时间轴多条轨道，规则见第 11 节。

决定：日程与提醒交给 Agent 管理；「今天」只展示记录、提供「问 AI」和提案批准，不放手动新建、编辑或日期表单。模型设置的排版：同一标题行的分页、四项统计、来源卡片与调用图、对齐的模型角色行、可搜索及按能力筛选的选择面板。模型选择仍按本规范原地展开。

## 1. 设计逻辑

1. **一体的窗口**：所有页面浮在同一张背景上。没有侧栏方块、顶栏方块，也不用层层叠起的卡片区分区域。
2. **层次靠底色和间距**：窗口背景之上最多再叠一层面板。区分内容先用间距，再用细分隔线，最后才用淡底色。只有选中和聚焦会描边。
3. **原地展开**：新增、编辑、确认、提示词编辑都在触发它的行下展开。只有系统必须接管的场景才弹窗：权限请求、选择文件、颜色面板。
4. **每页一个标题**：页面只有一个 title 级标题。小节标题下默认不加说明；说明只在影响决定的地方出现一次。
5. **每个区域一个主操作**：一个区域最多一个实心按钮，其余操作是轻按钮。
6. **状态有固定说法**：同一种状态在任何页面都用同一个标签、同一种颜色。
7. **组件先行**：页面只组合组件和设计参数，不自己挑字号、圆角、底色。需要新样子时，先在 `DesignSystem/` 加组件或变体，并放进样张页。

## 2. 风格

三种风格共用全部参数和组件，只在背景和「面板如何与背景分开」上不同。

| 风格 | 背景 | 面板与背景的区分 | 浮动面板 |
|---|---|---|---|
| 氛围 | 随内容变色的柔光，上面一层可调毛玻璃 | 淡底色 | 系统材质 |
| 毛玻璃 | 窗口后方桌面被模糊，上面一层均匀底色（中性或自选） | 淡底色 | 系统材质 |
| 纯色 | 一种平的颜色（中性或自选色轻微混入） | 白色面板（深色下为提亮的灰）加柔和阴影；面板内的面板改用淡底色，不再抬起第二层 | 实色面板加阴影 |

- 风格保存在用户设置里，通过环境值传给所有组件；组件自己根据风格选择画法，页面不判断风格。
- 新组件需要「面板感」时使用 `panelSurface`；悬浮在内容之上时使用 `floatingSurface`。不要直接画白底或材质。

## 3. 文字

七级，从大到小：display、title、section、headline、body、secondary、caption。

| 级别 | 用于 |
|---|---|
| display | 时钟和大号数字 |
| title | 页面唯一标题 |
| section | 页面内的小节 |
| headline | 行标题、导航项、卡片标题 |
| body | 正文、字段、按钮 |
| secondary | 行内说明、决定处的提示、元信息 |
| caption | 标签、计数、坐标轴 |

- 用 `typography(_:)` 设置文字，需要时只改字重；不写具体字号。
- 原地变化的数字（时长、计数、时钟）使用等宽数字。
- 地址、代码、模型 ID 用等宽字。
- 颜色层级只用 primary、secondary、tertiary 三档。

## 4. 颜色

颜色只表达含义；装饰交给背景和应用自身的颜色。

| 含义 | 用法 |
|---|---|
| 交互色 | 主按钮、选中描边、聚焦光晕、「已修改」等表示用户改动的标签。跟随系统强调色，不另设品牌色。 |
| 完成、警告、错误 | 只用在状态点和就地提示。 |
| 录制中 | 只给正在进行的采集，不用于删除等危险操作之外的强调。 |
| 去向 | 本机、自建、云端三种，各有固定颜色，只出现在去向标签和对应图标上。 |
| AI 渐变 | 只标记 AI 页和 AI 生成的内容，不用于普通控件。 |
| 应用色 | 由应用图标提取，用于时间线和片段；同一个应用每次得到同一个颜色。 |

## 5. 表面、圆角与间距

- **底色四档**：wash（原地展开的面板）、fill（字段和闲置选项）、hover（悬停）、selected（选中、按下）。都是主文字色的低透明度，在浅色和深色下都成立。
- **细分隔线**只分隔列表行；组与组之间靠间距。
- **圆角四级**：small（字段、行内缩略图）、medium（选项卡片、编辑框）、large（展开面板、悬浮卡片）、card（媒体卡片、大预览）。两端全圆的一律用胶囊形。圆角都是连续曲线。
- **控件高度三档**：chip（标签、小胶囊）、button（选项、轻按钮、主按钮）、field（字段、顶栏圆形按钮），保证同一行控件对齐。
- **间距**按 4 的倍数：行内元素用 xs，行与行用 row，组与组用 l，页面左右用 page。
- 滚动内容到顶栏前要淡出（`fadesUnderChrome`），不能从导航文字下面穿过。

## 6. 组件与用法

| 需要 | 用 | 不要 |
|---|---|---|
| 区域的主操作 | `PrimaryButton`，可设为回车默认 | 一个区域放两个实心按钮 |
| 其他操作 | `QuietButton`，悬停才显底色 | 系统带边框按钮 |
| 一组并列的操作（标题、摘要、标签…） | `SecondaryButton`：浅底胶囊 | 系统白底按钮 |
| 删除等不可撤销操作（在它自己的行里） | `ConfirmButton`，原地二次确认 | 系统确认对话框 |
| 删除等不可撤销操作（从菜单、卡片发起） | `confirmCapsule`：顶栏下浮动的确认条，写清后果 | 系统确认对话框 |
| 文字中间的小操作（问 AI、展开、撤销） | `ChipButton`：浅底胶囊，静止时就看得出能点 | 静止时像正文的文字按钮 |
| 可能要等一会儿的 AI 操作（回顾、会前要点、运行技能） | `RunButton`：点后变成转圈加说明加「取消」，取消真的停止运行 | 点了没有反馈、不能中途停止 |
| 顶栏图标操作 | `ChromeButton` | 自绘方形图标按钮 |
| 顶栏或标题旁的「更多」菜单 | `ChromeMenu` | 系统无边框菜单（`menuStyle(.borderlessButton)`，样式检查拦截） |
| 次要的文字菜单（速度、添加回退） | `QuietMenu` | 同上 |
| 切换同一内容的不同视图 | `PillSwitcher` | 系统分段控件 |
| 设置取值（约五项以内） | `CapsuleChoice` | 系统分段控件、单选按钮 |
| 设置取值（更多项） | `MenuChoice`：浅底胶囊显示当前值和小箭头，列表用系统菜单 | 系统弹出按钮、`Picker` |
| 打开一小组动作（生成草稿 → 标题/摘要…） | `MenuButton`，外观同 `MenuChoice` | 带边框的 `Menu` |
| 开和关 | `SwitchRow`（系统 switch） | 复选框 |
| 同一对象的几个独立开关 | `ToggleChip`（如应用的截图、文字、排除） | 一排复选框或 switch |
| 整数步进 | `StepperControl`：数值文字加小步进器 | 只有步进器、看不到值 |
| 一项设置 | `SettingRow`：左侧标题（有后果时加一句说明），右侧控件 | 系统 grouped `Form`、`LabeledContent` |
| 设置分页与分组 | `SettingsPage`（一个 section 级标题）、`SettingsGroup`（headline 级组名，可带右侧操作） | 系统 `Section` |
| 不常用的高级项 | `FoldRow`，在原地展开 | `DisclosureGroup` |
| 文本输入 | `QuietField`，标题在上 | 带边框文本框 |
| 页内搜索 | `SearchField` | 带边框文本框 |
| 长文本、提示词 | `PromptEditor`，放在 `InlinePanel` 中 | 弹窗编辑 |
| 行下展开的内容 | `InlinePanel` | sheet、popover |
| 顶栏按钮的下拉内容 | popover，内部只用本表组件 | 自绘浮层 |
| 选择日期（首页标题） | `DateJumperView`：popover 月历，记录量用强调色深浅表示，空日变淡，今天描边、当前日填色 | 系统日期选择器 |
| 一组可选的起点 | `PresetTile` 网格 | 下拉菜单里的长描述 |
| 默认或已修改 | `StateTag` | 自定义文字 |
| 一般标签 | `Tag`：灰色陈述事实，有色表达含义 | 自定义胶囊 |
| 内容去向 | `DestinationTag` | 自定义颜色 |
| 来源身份、七天调用与比例 | `SourceBadge`、`ActivityBars`、`ProportionMeter`，只用真实数据 | 虚构在线状态、费用或调用曲线 |
| 设置行里的图标操作 | `IconChipButton`，带可读名称 | 页面自己拼一套按钮 |
| 连接或采集状态 | `StatusDot` | 只用颜色、不配文字 |
| 就地的问题或提示 | `InlineMessage` | 横幅 |
| 别处发生的事 | `NoticeCapsule`（顶栏下浮动） | 系统通知、弹窗 |
| 悬停卡片、预览 | `floatingSurface` | 自绘阴影和边框 |
| 小节 | `SectionHeader` | 加粗正文 |

## 7. 反馈与空状态

- 错误写在出问题的地方：字段下、行内。别处发生的事才用顶部浮动提示。
- 错误文字说清发生了什么和下一步，例如「服务返回 401，需要访问令牌」。
- 空状态写清缺什么，并直接给出下一步按钮；不放插图和口号。
- 需要授权时，「授权」按钮放在对应能力旁边，并说明用途。
- 录制时必须有持续可见的动态反馈（波形或光球），红色只留给正在录制。

## 8. 动效

- 只用 `Motion` 中命名的动画：spring 用于页面与布局，snappy 用于悬停、选中和标签变化，bouncy 用于用户主动的切换与落位，magnify 用于跟随指针，ambient 用于背景换色。
- 全部用可打断的弹簧，新手势总能打断进行中的动画。只有跟随实时信号的数值（电平、播放进度）用匀速。
- 内容进场用 `Motion.enter`（淡入并上移一点）；行下展开用 `Motion.unfold`。
- **待实现**：系统开启「减少动态效果」时，弹簧和位移改为淡入淡出。

## 9. 无障碍

- 图标按钮都有无障碍标签；纯装饰元素隐藏。
- 选中状态加 `isSelected`；组合行合并为一个无障碍元素。
- 文字和背景对比在三种风格、浅色和深色下都要可读；验收时检查样张。

## 10. 检查与验收

- **自动检查**：`apps/macos/script/test.sh` 先运行样式检查（`script/check_style.sh`）；`DesignSystem/` 以外出现写死字号、写死圆角数值、自定义底色透明度，或本页第 6 节替换掉的系统控件（grouped `Form`、`GroupBox`、确认对话框、复选框、分段控件、`DisclosureGroup`、系统分隔线等）时，测试失败。确实属于画面内容的几何（如时间轴刻度、截图里的示意窗口）在同一行注明 `// style-exempt: 原因`，并且只用于内容绘制，不用于控件。
- **样张**：新增或修改组件时同步更新样张页。
- **截图验收**：改动界面后，用测试副本截取相关页面；氛围和纯色两种风格、浅色和深色都要看。毛玻璃的背后模糊由窗口服务合成，测试副本截图拍不到，需要在真实窗口确认。

<a id="list-detail"></a>

## 12. 列表加详情的页面

连接页与设置页同一结构：左侧按类别分组的列表（图标、名称、状态点），右侧是选中项的详情面板（一句说明、关键数字、授权、该项自己的设置）。规划中的项目折叠在列表底部。新增来源只在列表里加一行，不新增卡片区块。AI 页按「自动处理 / 流程 / 人物与声纹」与「手动生成 / 最近任务」左右两栏组织，规划中的能力缩成底部一行。

## 11. 主页时间线（多轨）

信息顺序：上方舞台回答「此刻在做什么」，下方轨道回答「这一天发生了什么」，两者共用一个播放头。

- **舞台**：左侧文字（应用、标题、时间、同一时段的录音/AI 指令/截图，每行可点），右侧一张当前截图，前后片段只在两侧淡出露出。舞台只放一张图，成堆的截图交给截图轨。时间线拉高到舞台不足约 190pt 时，舞台收成一行。
- **轨道**：自上而下为屏幕、截图、AI、录音；日历等新来源接入后再加轨。轨道名只是标签（悬停显示说明），单击无动作；显示哪些轨道在右键菜单「显示的轨道」里勾选，屏幕轨始终显示。高度只调一个值（顶部横条拖动，吸附紧凑/标准/展开三档），各轨按比例变化，用户不逐条调。
- **细节层级随缩放**：屏幕轨图标悬浮在细色条上方，挨近时折成「+N」；同一应用中途 3 分钟内的切换折入同一片段并画缺口；窄于 16pt 的连续片段合成一段彩条，单击放大到这一段。截图轨矮时是色点，高时是胶片条：胶片格按固定钟点分组（5、10、30 分钟……随缩放选最短放得下的一档），滑动时整条平移、不重新分组也不换图，只有缩放跨档才重排；每格默认显示该时段第一张并标张数，悬停左右移动逐张预览，换图时旧图留到新图就绪。AI 轨矮时只有指令点和工作条，高时显示指令文字。
- **屏幕轨标题**：只给可见图标配标题，文字止于当前片段、下一个可见图标或视野边缘；空间不足则省略或不显示。折入「+N」的邻居不再显示独立标题；完整名称由图标的可访问名称及片段详情提供。
- **打开**：详情在舞台位置原地展开，时间线留在下方并高亮该项；Esc 关闭，←→/↑↓ 在片段内切换。片段详情左列为可竖向滚动的时刻列表（缩略图、时间、窗口；中途切到别的应用也成一行），中间大图单击后铺满整个窗口放大（盖住导航；捏合/双击放大、拖动平移，←→ 换上一张/下一张，Esc 或空格关闭），右列只放「这段在做什么」「同一时间」（AI 指令、录音）和折叠的屏幕文字，识别与记录信息收进「技术细节」。
- **AI 轨**：只画时刻点，悬停或打开某条时才淡显其后的工作时长；悬停卡片写来源（Codex / Claude Code）· 项目文件夹 · 会话名（会话标题，缺失时用该会话当天第一条指令开头）、原话前两行、时间、工作时长与当天本会话第几条。AI 指令详情优先显示已保存的原话，打开即从会话文件现读其后的回复（不存进时间线），读到下一条指令为止；读不到时只加一行提示。标题栏有 ‹ ›（或 ←→）按时间切到当天上一条/下一条，叠在同一处的几条也由此逐条看；「打开来源」菜单列出能做的跳转：在终端继续会话（`claude --resume` / `codex resume`）、复制该命令、在访达中显示会话文件、打开项目文件夹。
- **右键**：片段、合并段、截图、AI 指令、录音、空白处和轨道名各有菜单；只弹菜单，不改变选择、播放头和视野。破坏性操作仍走 `confirmCapsule`。

<a id="timeline-interaction"></a>

### 11.1 交互规则

原则：看和定位分开；一次操作一个结果并立即生效；手动移动过的视野不被自动拉回；新数据不打断操作。

| 操作 | 结果 | 不会发生 |
|---|---|---|
| 双指滑动、鼠标滚轮 | 视野平移，跟手 | 播放头和舞台不动，不回弹 |
| 捏合、⌘+滚轮 | 以指针为中心缩放 | 播放头不动 |
| 单击空白轨道或刻度 | 播放头移到该时刻 | 不打开详情 |
| 按住拖动 | 拖动播放头，靠边自动平移 | 拖动中不重排、不闪烁 |
| 单击片段、录音或截图 | 定位：播放头到该项，舞台显示它；合并块放大 | 不直接打开详情 |
| 再点已定位的项、双击、单击舞台卡片、回车 | 打开详情；详情已开时单击轨道项直接切换内容 | 不先显示别的再跳 |
| 单击 AI 指令点 | 原地展开 | — |
| 播放头移出视野 | 边缘出现「◀ 时间」标签，点它带回 | 不自动拉回 |
| 「回到现在」、跳转、方向键、播放 | 视野跟到播放头 | — |

- **跟随现在**：今天且未手动定位时，播放头随时间前进，视野只在播放头接近右缘时平移；一定位或拖动即退出，出现「回到现在」。
- **新数据**：拖动、滚动、捏合期间到达的新记录在停手约 0.3 秒后合并；时间线构建在后台完成、最多约每 0.5 秒一次，合并不移动视野。

<a id="menu-bar-panel"></a>

### 11.2 菜单栏面板

点菜单栏图标开关面板；点面板外、切到其他应用或按 Esc 立即关闭；面板里「打开主窗口」执行后关闭，开关类操作保持打开。实现为 `NSStatusItem` + transient `NSPopover`（`StatusItemController`）。
- 几何规则（合并、折叠、分桶、高度）在 `TimelineLaneLayout` 中实现并有单元测试；数值只在那里和 `DesignSystem/` 中定义。
